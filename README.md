# Sistema Sonno — sito

Output statico pubblicato su Netlify (progetto `sistema-sonno`, dominio `cosimosgobba.it`).

Ogni commit su `main` pubblica il sito. Non c'è compilazione: il contenuto di questo
repository è esattamente ciò che viene servito.

Il sorgente con i `partials/` e `build.js` sta nella cartella di lavoro locale
(`Sistema Sonno v.04`); qui arriva solo il risultato di `node build.js`.
